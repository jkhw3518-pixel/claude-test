간단한 그래픽의 야구게임을 만들어줘.
플레이는 타격과 피칭부분으로 나뉘는데, 타격 부분에서는 우타자가 투수의 공을 타이밍에 받아치는 형식으로, 피칭은 좌투수가 포심, 슬라이더, 커브, 포크볼을 스트라이크존에 넣는 형식으로 만들어줘.
팀이름은 미국 내 각 도시에서 따와 랜덤으로 만들어줘.
시작하기 전에 선수의 프로필을 만들 수 있게 해줘. 프로필엔 이름, 국적, 포지션, 나이, 소속 팀을 선택할 수 있게 해줘.
국적 부분에 있어선 모든 국가가 호환될 수 있게 만들어줘
플레이어 이외의 선수들도 생성선수로 만들어줘
특별한 로그인 과정은 생략해줘.
